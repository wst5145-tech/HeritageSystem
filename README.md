# Chinese Cultural Heritage Visualization System

A web-based visualization system designed for the digital storage, retrieval, and spatial presentation of Chinese cultural heritage. 

## ✨ Features
- **Multi-language Support**: Seamless switching between Chinese, English, and Russian for the UI and historical metadata.
- **Map Visualization**: Interactive map rendering heritage distribution without third-party map APIs (using pure Canvas/ECharts).
- **Advanced Filtering**: Filter by dynasty, heritage type, and keyword search.
- **Rich Interaction**: Hover markers to view detailed information in the selected language.

## 🛠 Tech Stack
- **Backend**: Python, Flask, PyMySQL
- **Frontend**: HTML5, ECharts, Vanilla JavaScript
- **Database**: MySQL (utf8mb4)
